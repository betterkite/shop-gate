# 零售看板模板

本文件用于按 run plan 的 `visualization.templateId` 选择零售页面结构。只读取匹配的二级标题；模板名称和必备组件用于生成与校验，不直接展示给用户。

## funnel-analysis：浏览到购买的转化过程

适用：用户希望了解页面浏览、收藏、加购、购买之间的流失。

必备：

- 总览指标：页面浏览量（PV）、独立访客数（UV）、收藏、加购、购买和购买转化率。
- 事件数量与独立用户触达率分开显示，不能把用户数和事件数混在一列。
- 按日趋势、商品/类目拆解、明细入口和数据窗口说明。
- 当购买大于页面浏览时显示数据异常，不用图形比例掩盖问题。

## catalog-structure：商品与类目结构

适用：商品排名、类目比较、集中度和经营结构分析。

必备：

- 排名表展示全部可分页商品或类目；排序字段、窗口和当前筛选范围可见。
- 同时显示页面浏览量、购买量、成交总额、购买转化率和库存等可用字段。
- 需要下钻时保留 `dataset_id`、维度和值，并提供返回上一级入口。
- 数据不足时保留缺失字段和原因，不用默认值制造排名。

## price-inventory：价格与库存健康

适用：库存风险、库销比、补货参考、价格带和价格观察。

必备：

- 库存数量、近窗口销量、库销比/可售天数和供货假设分别标注。
- “需关注库存商品数”说明其规则来源，商品明细可按关注类型筛选和分页。
- 价格带显示商品数、浏览、购买、购买转化率、成交总额和利润字段的真实口径。
- 价格弹性只有在同一商品存在多价格观察时展示；没有实验分组时明确标记为观察或模拟参考。

## analytics-bi：综合经营工作台

适用：需要总览、趋势、用户、渠道、利润、库存、生命周期和行动建议的 BI 经营分析。

必备：

- 顶部范围栏：数据集、统计窗口、商品/类目/渠道筛选和数据状态。
- KPI 指标、日趋势、用户分群、渠道/活动、利润、商品生命周期、留存和库存模块。
- 每个模块有摘要、明细入口、分页或筛选，不只显示前三/前五条。
- 当前筛选变化后，同一页面的摘要、图表、表格和链接保持一致。
- 行动建议只能引用已验证的异常和字段，且附带数据限制。

## daily-brief：经营日报

适用：最近一天的经营变化、类目异动和需要优先查看的事项。

必备：

- 统计日、比较日和比较方法清楚可见。
- 总量、环比、类目变化、商品明细和异常原因分开呈现。
- 变化不具备足够样本时显示“样本不足”，不生成确定性判断。
