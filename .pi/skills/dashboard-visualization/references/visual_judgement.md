# 零售经营指标判读清单

画图前先确认四件事：时间字段、业务维度、指标字段、指标口径。把事件数、去重用户数、金额、库存快照、比例和比率分开处理。

## 先判断数据

1. 确认数据集身份、统计窗口、来源、更新时间和行数。
2. 确认页面浏览、收藏、加购、购买是否是行为事件，商品价格是否来自数据集。
3. 确认商品/类目/渠道/活动/用户维度是否真的采集；没有数据不能推断维度表现。
4. 确认是否有库存快照、成本、活动价格、多价格观察和实验分组。

## 指标口径

- 页面浏览量（PV）：窗口内页面浏览事件数。
- 独立访客数（UV）：窗口内发生页面浏览的去重用户数。
- 购买转化率：购买事件或购买用户除以明确的页面浏览分母，页面必须写清采用哪一种。
- 成交总额（GMV）：购买数量乘以数据集中的实际商品价格；缺价格时显示缺口。
- 动销占比：窗口内发生购买的有库存商品数，除以统计时点全量有库存商品数。
- 库销比/可售天数：分别使用已验证的库存和销量口径，不把库存地板值当成真实销量。
- 毛利/利润：只有成本字段存在时才展示；否则说明无法计算。
- 留存：按首购周或首购日定义 cohort，并只对完整观察窗口计算。
- 价格弹性：需要同一商品的多价格观察；真实实验、观察关系和合成模拟必须分开标记。

## 图表选择

- 日趋势：折线图或面积图，显示日期轴、图例、数值和当前窗口。
- 阶段/分类比较：排序条形图配明细表，保持统一刻度。
- 转化过程：事件数和去重用户数双列/双层展示，避免只画一个比例。
- 利润与库存：金额、件数、天数分开显示，必要时使用双图而不是双轴混淆。
- 明细规模较大时使用表格、分页和筛选作为主核对入口，图表只做摘要。

## 用户文案

用户看到的是结论和原因，不是内部字段名。首次出现缩写时使用“中文名称（缩写）”；诊断说明写“发现了什么、可能原因、建议查看什么数据”，避免只写“异常”“风险”“下钻”而不解释下一步。
