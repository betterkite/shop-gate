# Shop Gate UI/UX 适配规则

## 设计顺序

1. 判断产品类型和用户任务。
2. 选择页面模式：工作台、实时运营、数据平台、任务详情或设置。
3. 选择数据密集型但克制的视觉风格。
4. 统一配色、字号、间距、组件和状态语义。
5. 应用可访问性、响应式、表格和图表规则。
6. 用状态矩阵、构建、smoke 和视觉检查验证。

## 默认设计系统

- 产品类型：零售经营 AI 工作台、数据平台、任务与运营控制台。
- 页面模式：入口页使用紧凑的实时运营工作台；分析页使用数据密集型 BI 画布。
- 视觉：中性表面、清晰边框、轻阴影、紧凑间距和稳定表格。
- 色彩：蓝色表示信息/运行，绿色表示完成，琥珀表示提醒，红色表示失败或风险，灰色表示未知。
- 字体：使用系统字体和等宽数字；不引入远程字体。

## 页面与数据规则

- 首屏展示真实数据、当前数据集、时间窗口、主要操作和可核对的图表或表格。
- 图表必须有图例、标签、数值提示和表格/明细替代入口。
- 页面必须处理 loading、empty、error、pending、disabled、长文本和权限缺失。
- 不把内部模板名、端点、缓存状态、文件路径或验证状态当成用户侧内容。
- 切换数据集、筛选维度或日期后，摘要、图表、列表和链接一起更新；返回入口恢复上一级范围。

## 反模式

- 巨型 hero、整页渐变、装饰性插画和卡片套卡片。
- 只显示前几条但没有“查看全部”、分页或筛选。
- 只用颜色表示状态，或用图表形状制造数值大小错觉。
- 远程脚本、远程图片、远程字体和浏览器直连外部服务。
