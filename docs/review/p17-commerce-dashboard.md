# ISSUE-P17：电商经营分析体验与生成看板视觉升级

## 背景

本项目已经具备真实 UserBehavior 行为事件、合成商品主数据和四类零售生成模板，但当前交付仍有三处断点：

1. 商品运营与经营情报页面没有统一的返回经营工作台入口，页面层级和主工作台不一致。
2. 商品表格在窄屏下被迫按单字换行，经营情报页面缺少“结论—证据—行动”的视觉层级。
3. 生成看板虽然能展示指标和图表，但部分历史候选仍显示旧金融文案或已停止的预览；日报模板的内容密度也不足以支撑运营判断。

用户提供的知乎文章 `https://zhuanlan.zhihu.com/p/685913580` 在本轮抓取超时，因此不把它作为已经读取的直接证据。本切片参考了可访问的相关电商 BI 资料，提炼出一致的分析路径：先看核心指标是否达标，再看趋势与异常，再定位到类目/商品/渠道，最后给出可执行动作；同时补充流量、转化、用户/商品结构、库存、利润或合成 GMV 口径等视角。

## 实施范围

- 复用 `PageHeader` 与 `PlatformSwitcher`，给商品运营、经营情报接入统一产品导航和“返回经营工作台”按钮。
- 重排两个页面的首屏：窗口/来源/合成口径 → KPI 总览 → 趋势或排名 → 异常/观察 → 明细证据。
- 修复窄屏表格布局，使用可横向滚动的最小表宽，禁止中文字段逐字断行。
- 扩充零售生成模板的日报/看板层级，至少包含：
  - 总览：GMV、曝光、购买、转化、客单价等；
  - 趋势：分日曝光/加购/购买或日环比；
  - 异常：转化、GMV、库存健康度、类目集中度；
  - 拆解：类目、商品、渠道、价格带；
  - 行动：补货、转化优化、商品结构复核、继续观察。
- 清理本轮会触达的旧金融可见文案：生成结果标签、快捷问题、共享页面头部标识和导航说明。

## 数据口径

行为事件优先使用 `behavior_source=tianchi_userbehavior` 的真实行为流。当前数据层无法提供真实价格、库存、品牌、店铺和金额时，允许使用稳定生成的合成商品主数据；合成 GMV 按“购买事件 × 合成价格”计算。所有相关页面和生成看板必须显示“合成口径”，不得把合成金额写成真实成交金额。

本切片不伪造利润或广告 ROI。若未来新增利润/投放数据，必须在数据契约中声明字段来源、时间窗口、聚合方式和缺失策略后再加入指标。

## 验收清单

- [ ] `/commerce-platform`、`/operations-briefing` 均显示返回经营工作台入口，并可通过产品导航切换。
- [ ] 1440px 首屏能同时看到页面标题、数据来源、核心 KPI 和第一块分析内容。
- [ ] 390px / 640px 下表格不逐字换行；数据可横向查看，页面不产生横向溢出。
- [ ] 生成的四类零售看板均保留数据来源、合成口径和数据窗口说明。
- [ ] 生成日报同时有指标总览、环比/趋势、类目拆解、重点关注和行动建议。
- [ ] 生成代码不再输出“交互式金融看板”、金融快捷问题或 `synthetic-badge` 的原始 HTML 字符串。
- [ ] 模板构建、type-check、单测、文档/技能/模块边界检查和 `check:retail-e2e` 通过。
- [ ] 真实 DeepSeek 验收产生的预览可重新启动；已停止预览不会被误报成“看板待生成”。
