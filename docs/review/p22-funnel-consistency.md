# ISSUE-P22：合成行为漏斗一致性

## 问题

合成行为生成器此前独立随机生成收藏、加购和购买商品。虽然全局样本通常满足 `PV > Buy`，但商品级或日级聚合可能出现购买量高于页面浏览量，无法解释为正常电商漏斗。

## 处理

- 收藏、加购和购买只能从同一用户当日已浏览商品中抽样。
- 保留头部/腰部/长尾流量分布和周内季节性。
- 增加商品×日漏斗边界测试，约束 `Fav/Cart/Buy <= PV`。
