# ISSUE-P23：BI 看板指标图形与用户文案不一致

## 发现

- 原趋势图把 PV、加购和购买放在同一张坐标区域，并对每条线单独缩放。这样虽然能看出涨跌，但会出现蓝色 PV 线视觉上低于绿色 Buy 线的情况，容易被理解为购买量超过浏览量。
- 趋势图说明写成了 `PV/UV/购买`，但图中实际画的是 PV、Cart、Buy，没有画 UV。
- “合成价格”“合成口径”“行为流”等表述偏内部实现语言，用户不容易理解。

## 处理

- 趋势图保留一张图，但统一使用同一个真实数量刻度，避免跨指标分别缩放造成线条高低错觉。
- 删除趋势说明中的 UV，明确三条线分别表示什么，并在图例中显示最新数值。
- 用户界面统一使用“演示数据”“商品价格（估算）”“用户行为数据”等更直白的表述；保留英文缩写帮助熟悉 BI 的用户识别。
- 说明 UV 是“看过商品页面的不同用户数”，PV 是“打开商品页面的次数”，GMV 是“购买次数 × 商品价格”的估算值。
- 商品运营、经营日报、能力中心、日报生成内容和生成看板模板同步更新。

## 验收记录

已完成：

- 模板单测通过，确认趋势图说明只列出实际绘制的 PV、Cart、Buy，不再误写 UV。
- 趋势图使用单一真实数量刻度；全量数据的 `PV >= Buy` 约束保持成立，避免视觉缩放制造反向关系。
- 前端类型检查、Lint、生产构建和完整 release gate 通过；前端测试为 `1,020 passed`，后端测试为 `18 passed`。
