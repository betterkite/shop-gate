# ISSUE-P24：BI 看板表头与诊断文案用户化

## 发现

- 渠道和类目表仍使用“GMV 份额”“流量份额”“库存风险数”等内部字段名，用户需要额外理解英文缩写或数据字段。
- 库存明细使用“风险”“诊断”“库销比”等词，不能直接说明为什么需要关注以及下一步做什么。
- 高流量低转化模块的表头和建议也偏内部分析语言。

## 处理

- `GMV 份额` 改为“成交总额（GMV）占比”。
- `流量份额` 改为“浏览量占比”。
- `库存风险数` 改为“需关注库存商品数”。
- `诊断` 改为“原因与建议”，“风险”改为“关注程度”。
- `库销比` 在用户界面改为“库存可售天数（估算）”。
- 将“高流量低转化”改为“高浏览低购买”，并把建议改成“浏览较多但购买偏少，建议检查商品页和价格”等可执行表述。

## 验收记录

已完成：

- 模板单测通过，确认用户界面不再使用“GMV 份额”“库存风险数”等旧表头，并包含“成交总额（GMV）占比”“需关注库存商品数”“原因与建议”。
- 商品级库存诊断已按数据情况输出可执行说明：浏览较多但购买偏少、当前窗口没有购买、继续关注库存周转等。
- 重新生成并构建验收看板；浏览器确认渠道、类目、库存问题和高浏览商品模块均显示完整中文和用户可理解的建议。
- 前端类型检查、Lint、生产构建和完整 release gate 通过；前端测试 `1,020 passed`，后端测试 `18 passed`。
