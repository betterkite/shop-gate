# ISSUE-P25：需关注库存商品数的含义与补货边界

## 发现

“需关注库存商品数”容易被理解为“需要补货的商品数量”，但当前指标只是对库存和购买表现异常的商品做提醒，并不是补货决策。

## 处理

- 在类目拆解表头增加说明：该数量表示达到关注规则的商品数，例如库存可售天数较高、窗口内没有购买，或浏览较多但购买转化偏低。
- 在库存健康度说明中明确：需关注不等于立即补货，必须结合库存数量、窗口销量、页面浏览量和购买转化判断是库存积压、商品页/价格问题，还是确有补货需求。
- 保留“原因与建议”明细，让用户先处理商品页、价格、曝光和库存周转问题，再决定补货。
- 类目拆解脚注删除重复的“它只是提醒，不等于立即补货”句子，保留判断依据，让说明更简洁。
