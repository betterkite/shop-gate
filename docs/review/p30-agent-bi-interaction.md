# ISSUE-P30 Agent 多轮下钻与 BI 交互（进行中）

## 本次推进

本次先补齐最容易造成 Agent 误判的商品级证据：商品下钻不再只看订单和库存，还会读取同一 `dataset_id` 下的行为事件，返回页面浏览量（PV）、收藏、加购、购买和购买转化率。这样 Agent 可以回答“商品被浏览了多少、加购了多少、最后购买了多少”，并在下一轮继续沿渠道、价格带、类目或转化问题下钻；同时返回基于当前证据的用户化建议动作。

同时补齐类目维度。`category` 与商品、渠道、活动、用户一样保留数据集隔离，并返回类目级行为漏斗和转化率；数字类目 ID 不被当作商品 ID 解释。

- 普通指代型追问（如“这个类目里哪个商品购买转化率最低？”）在没有新实体时会继承上一轮实体、数据集和时间范围；明确指定新商品/类目时不会继承旧实体。新增回归测试覆盖这两种边界。
