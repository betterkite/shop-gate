# ISSUE-P31 数据集选择与分析联动（第一片）

## 本轮范围

本轮先完成已注册数据集的选择与分析页面联动，不伪造尚未存在的导入事件或异步生成能力：

- `/analytics-workbench` 读取 P27 的 `GET /api/v1/commerce/datasets` 契约列表；
- 页面提供数据集选择器，显示数据集来源、窗口、契约版本、记录数和合成字段；
- 切换数据集通过 `dataset_id` 和当前视图重新请求全部分析接口；
- 当前数据集不在契约列表时，自动回退到列表中的第一个已注册数据集，并给出可理解的状态；
- 下钻视图切换数据集时保留维度和值，其他视图不会共享旧数据集的服务端结果；
- 所有请求使用 `cache: no-store`，避免切换后继续展示旧的分析响应。

## 验收

- P27 数据集契约接口已存在并作为唯一数据集来源；
- 页面类型检查通过；
- 文档链接检查通过；
- 浏览器验收需确认：选择器显示当前 `retail-demo-expanded-v1` 的窗口、来源、记录数和合成字段；切换到另一个已注册数据集后 URL 和页面数据同步变化；无效 `dataset_id` 不会把旧数据继续当作当前数据展示。
