保留 Shop Gate 品牌、青蓝主题、深浅色及已有认证和 Agent 治理基础，独立实现完整电商 BI，并将经营分析助手嵌入八个业务模块。不是继续补齐几个固定看板模板，也不是把参考项目整体搬入本仓库。

## 不变边界

- 正式经营数据使用现有 PostgreSQL 服务边界，不引入 SQLite 作为第二套正式账本。
- 成交来自订单明细，不用行为购买次数乘当前价格代替；缺成本、映射、汇率必须保留未知状态。
- 所有列表可访问全量，默认服务端每页 20 条；汇总和导出不依赖当前页。
- 基础 BI 无需模型也可用；助手默认回答、表格和相关图表，不生成整页源码、不硬套模板、不强制跳页。
- 修改成本、映射、目标、导入和历史账本需预览、明确确认、权限、版本、幂等及审计。
- 六项可信检查与现有 CI 均保留。独立隔离验证与 Agent 自述区分记录。
- 旧会话和成果保留必要只读访问；未证明无引用之前不删除旧实现或用户数据。
- 用户2026-10-11更新发布方式：各阶段本地分段提交与验收，中途不创建PR、不推送分支；全部完成后统一提交v0.1。发布门禁不降低，合并、标签、生产部署、破坏性操作仍按对应授权执行。
