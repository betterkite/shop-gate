# v0.1 验收与证据协议

R0只验证基线与流程。下面是完整目标的强制验收，不表示已运行。状态来自 [功能矩阵](feature-matrix.md)，不能以测试文件存在、HTTP200或截图文件存在替代通过。

## 每次验收记录

至少记录：功能ID、issue/PR、产品revision与工作快照、测试类型/可信profile、独立验证证据ID、环境与依赖、输入范围/数据版本、期望与实际、失败或跳过原因、私有日志位置、结论和残余风险。公开记录脱敏；凭据、原始会话、用户数据和本机绝对路径不提交。

状态为待实现→已实现待验证→已验证；代码、依赖、作用域或数据协议改变后检查证据适用性。合并后核对main revision与CI，不复用不适用的旧分支结果。

## 固定核算验收

- 手工可复算的独立小账本：成本三层优先级与时间区间、历史快照、标准单位换算、币种/汇率、费用余数分摊、无销售费用、未知成本/映射/汇率。
- 全额/部分/多次退款、仅退款、可回收退货、未发货取消、跨期/跨币种金额与数量上限。
- 全范围/分组/过滤/页面/导出/助手的金额精确一致；未分摊费用和已核算范围有明确差额说明。
- 当前成本与历史成本、未来成本变更与历史重算、付款归属与退款事件口径分开验证。
- 实际PostgreSQL执行迁移、引用/唯一键、事务回滚、两个并发客户端、幂等/冲突/预览过期、作用域隔离与备份恢复。模拟或SQLite结果不替代。

## 十二类CSV验收

每类运行有效导入、模板/字段下载、依赖/类型/精度/日期错误、完全重复、同键冲突、导出往返。另测BOM、中文、前导零、引号/换行、负费用、非有限值、超精度/超额/超时、多个文件依赖与末段失败整批回滚。预览不写账本；同幂等键不同内容拒绝；完全重复不增加版本。

展示报表公式保护与标准源数据可往返分别测试。批次、错误下载与标准导出均需权限和全量范围，不能只输出当前页。成功导入使缓存失效及页面刷新，但不自动发起付费模型请求。

## 八页真实浏览器

经营总览、平台、店铺、商品、利润费用、退款、报表、成本各自验收全部矩阵项。覆盖：两主题、加载/错误/空/未知/权限、日期与数据集、平台约束店铺、搜索/排序/20条分页/全量、滚动不跳顶、图表联动与撤销、详情及关联对象、前后退、旧链接、视图和目标重启持久化、导入/全量导出、模拟及正式操作确认。小屏重要操作不被遮挡，但不单独开发移动端产品。

先通过总览与商品详情的主题样板审核，再推广组件。交互和数据验收与视觉验收分别记录，不能互相替代。

## Agent固定集（至少32例）

下列A01–A32是最低集；复杂度增加可继续补充，不能以模型自评判定数值正确。每模块至少一例使用已授权真实模型（优先已有DeepSeek配置），同时保存受控查询/版本/证据和实值核对。可重复回放与真实模型集成证据明确区分。

| 模块 | 固定场景 |
| --- | --- |
| 总览 A01–A04 | 当前期间净销售/利润解释；下降的算术拆解；仅问答不生成看板；模型断开BI可用且助手如实说明 |
| 平台 A05–A08 | 各平台贡献/集中度；相关趋势图；继续看已选平台店铺；组件不足仍回答表格 |
| 店铺 A09–A12 | 继承店铺/日期的事实查询；全量排名；目标影响预览但不提交；确认后权限/版本校验 |
| 商品 A13–A16 | 1000规格排名可分页；跨店铺标准单位比较；缺成本与已知部分解释；映射建议与确认边界 |
| 利润 A17–A20 | 费用与利润形成核对；算术变化不宣称因果；未分摊费用解释；多轮继承同数据版本 |
| 退款 A21–A24 | 两种时间口径；仅退款/回收成本解释；部分退款原订单证据；无合理分母不编造比例 |
| 报表 A25–A28 | 当前范围全量表；明确要求才保存专题；切换数据集隔离上下文；旧版本结果明确标记 |
| 成本 A29–A32 | 层级优先级解释；只读试算不写账本；过期/重复/冲突确认拒绝；历史重算预览与明确确认 |

另测越权/伪造身份、工具SQL注入、请求源码修改、错误或无效模型输出、超时、取消、预算、审批恢复。有效完整问题不得强制问内部ID；真正歧义才最少澄清。新问题不能总靠新专属模板。

## 质量、持久化与性能

可信隔离验证保留单元、后端、类型、lint、构建、文档检查及现有CI；适用E2E不得无理由跳过或删测试。每次结果绑定精确快照；旧通过不能代表新代码通过。

目标、成本、映射、报表、导入和审计在服务重启/浏览器缓存清除后仍存在。正常启动不重置数据；演示重置仅在授权演示范围明确确认，正式数据不允许。迁移先备份并实际恢复演练。

1000规格/100000订单集测普通分页、筛选、总览p95≤3秒，记录机器/版本/样本、查询计划、冷热缓存、CPU/内存与数据规模。长导出/重算可跟踪状态，不阻塞页面。性能目标不得自行调低。

## 完成与阶段

工作台任务按todo→dev→sit→uat→prod有证据流转。本机测试只证明相应本机阶段；未经真实部署不可标prod或已上线。

最终须矩阵全项实现且验证、阻断及高严重度问题清零、八页与真实模型集完整、当前可信检查/CI通过、按授权合并后验收，并交付源码、迁移、模板、数据、安装配置、备份恢复、部署和残余事项。仅阶段通过或PR已创建不等于v0.1完成。
