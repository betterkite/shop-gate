# R2-B 数据集目录与授权创建

对应 [issue #87](https://github.com/betterkite/shop-gate/issues/87)。本片独立实现目录元信息、空数据集创建和用途分离的服务签名，不复制参考项目代码/数据。尚未注册HTTP路由、页面、长作业或启动生成；不能把服务函数当成已经可用的网页功能。

## 权限与数据边界

Node `src/lib/bi/gateway-scope.ts` 的 `issueDirectoryScope` 继续用真实登录、个人空间/共享项目成员和账号管理能力的交集，不接受浏览器或模型自报身份。目录令牌的目标是 `shopgate-bi-directory-v1`，只含工作空间、身份、能力与短效时间，没有数据集通配符或假版本。事实令牌仍限定数据集和版本；Python `ledger/scope.py` 分别验证目标与严格字段，二者不能交换。

前向迁移009新增 `bi.dataset_directory`，只包含名称、来源、版本、币种、状态与更新时间；读取按工作空间隔离。目录读取绑定空数据集作用域，所有经营事实仍保持006的严格工作空间+数据集RLS，无事实可见。目录写入另需当前目标数据集，删除无策略；同步触发器使用普通调用者权限，不是超级用户/SECURITY DEFINER。原数据集和目录版本在同一事务更新，失败一起回滚。

源身份、演示/正式来源和核算币种创建后不可重新归类，不能把正式数据改成演示数据再重置。迁移仅显式执行，在已有环境先备份与恢复演练；普通启动不应用DDL、不补数据、不重置。009旧数据回填只复制元信息，不产生订单或核算金额。

## 空数据集与明确创建

`ledger/datasets.py` 的 `create_dataset` 要求管理能力、明确用户确认及显式演示运行开关。演示关闭时仍能正常创建正式导入集；同一ID不能覆盖任何现有名称、来源或事实。优先建立新演示集，不删除用户修改过的演示。

创建事务同时建立工作空间（如尚不存在）、目标数据集、空账本revision1、目录和追加式创建记录。空集尚无经营记录，不能描述为已生成演示数据或真实零营业额。请求摘要、幂等键和身份受控；同请求重试返回原创建结果，同键异请求/其他身份重用拒绝。返回版本是该次创建的历史结果，切换/查询时必须读取当前目录版本，不能用历史创建结果作为最新账本版本。

`list_datasets` 只列当前空间的活跃元信息，默认20/页，稳定ID排序、完整数量和来源筛选；归档后不继续出现在可选列表。费用/订单数量和日期范围由选定数据集受控查询提供，不在目录同步时反复汇总事实。
