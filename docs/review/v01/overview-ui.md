# 经营总览与目标页面（R3 候选）

对应 [#91](https://github.com/betterkite/shop-gate/issues/91)。页面代码已实现不等于完成验收；以任务中的准确 revision、RepoSteward 验证和实际网页记录判断状态。

## 页面与数据流

`/bi`进入`/bi/overview`。工作台平台选择器及数据集中心提供总览入口，携带当前授权的工作空间、数据集。原页面和历史数据保留原路径，迁移清理仍在完整目标内。

- 服务端校验登录与工作空间读取权限，拒绝重复、无效的范围参数；登录返回路径只保留本产品拥有的字段。
- 先列出可访问数据集，每页20项；离开目录当前页的选中数据集按其编号单独读取。没有选择或读取失败时不自动替换成别的数据。
- 页面使用`POST /api/bi/overview`读取同版本总览。六指标、比较、完整日周趋势、平台排名、规则提醒、全部店铺月目标和核算完整度来自统一账本。金额保留十进制字符串，只有绘图坐标使用浮点。
- 平台贡献支持按净销售额或已核算贡献排序，分母覆盖全部所选范围，不能从当前20项计算；负数/非正合计/缺失金额有明确状态。
- 来源抽屉复用`POST /api/bi/query`，允许维度切换、搜索、排序和完整20分页。抽屉只收窄页面范围，不允许内部选择覆盖更窄的全局条件。可从真实平台、店铺、商品、规格、平台商品行应用筛选。
- 日期、退款口径、趋势粒度、平台/目标/来源页码与明细写入URL，使用`scroll:false`；重取数据保留页面空间，避免短暂加载压缩页面引发滚动。趋势图附全部日期表，断档不补零，日期可点击和撤销。
- 目标列表包含尚未设置目标的店铺，销售目标/经营贡献目标与实际金额、完成率独立显示；月目标只继承平台/店铺，明确整月口径。编辑器展示原值、新值、版本影响、有效期；第二次用户确认后调用受控写入。只读用户可查看，不显示提交表单。
- 数据集元信息轮询发现版本变化后重新读取，不自动调用付费模型。来源结果必须与工作空间/数据集/数据版本/核算版本相符；旧请求被取消且不能填入新范围。

## 当前剩余范围

1. 主数据筛选目录：当前来源选择只覆盖所选期间实际有经营记录的对象，页面明确说明。完整功能仍需支持无交易/费用的平台、店铺和商品，并显示名称，而非仅编号。
2. 经营提醒当前呈现观察与规则、提供全部来源；必须继续实现按具体缺项准确定位订单行、费用、退款等证据，不能把普通明细冒充已定位的异常。
3. 嵌入式助手尚未接入本页。必须继承同一范围和版本，完成受控查询、真实模型、多轮和治理；不得改成默认生成整页源码。
4. 全部实际网页流程、桌面/小屏/深浅色、返回/前进/刷新、滚动位置、预览/取消/确认/权限/并发和重启后目标持久化待验。SSR和URL测试不能代替网页点击。

## 自动化覆盖与验收关系

新增测试检查URL恢复与隔离、重复参数、无效日期、授权失败不泄密、人工121样例金额渲染、记录缺失/真实零/未知/不同退款口径的区别、完整23日期20分页。PG总览测试补充全渠道占比分母与负贡献不伪造占比；原目标维护真实PG/HTTP/Node测试一并走原`shopgate-full`六项与Git差异检查。最终结果记录在对应任务，旧版本的通过不自动覆盖本候选。
